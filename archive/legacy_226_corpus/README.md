# Legacy scripts of the withdrawn 226-contract evaluation

These scripts built, ran and plotted the author-labelled 226-contract corpus that an early
version of the paper used. The paper no longer reports that evaluation (its labels were not
independent), and no current script imports these files. Their docstrings and labels
("CEGAR", "proof") describe that earlier design and are not claims about the current engine.
They are kept only so the history of the project stays inspectable.
